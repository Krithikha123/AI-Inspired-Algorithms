AI-Inspired Algorithms

Optimization problems involve finding the best solution from many possible choices. In this project, AI-inspired algorithms are used to search for high-quality solutions efficiently. The system allows users to generate or load problem data, select an optimization algorithm, configure its parameters, run the algorithm, and view the final results through tables, charts, and visualizations. This system demonstrates how AI-inspired optimization algorithms can discover efficient solutions for real-world decision-making problems. Explore routing as the main application, along with scheduling, timetabling, and feature selection.

ALGORITHM LIBRARY

Optimization Algorithms

GA

Genetic Algorithm

It is inspired by natural evolution. It creates a population of possible solutions and improves them over generations using selection, crossover, and mutation to find the best solution.

SA

Simulated Annealing

It is inspired by the cooling process of metals. It gradually improves a solution and may temporarily accept a worse solution to avoid getting stuck in a local optimum.

ACO

Ant Colony Optimization

It is inspired by ants finding short paths to food using pheromone trails. Artificial ants build solutions, and better routes receive stronger pheromone values, guiding later ants toward efficient paths. It is a metaheuristic particularly suited to difficult combinatorial problems.

PSO

Particle Swarm Optimization

It is inspired by the movement of bird flocks and fish schools. Each particle represents a possible solution and moves by learning from its own best result and the swarm’s best result.

ABC

Artificial Bee Colony

It is inspired by honey bees searching for food. Candidate solutions are treated as food sources: employed bees explore nearby solutions, onlooker bees choose promising sources, and scout bees explore new random areas when a source is not improving.

APPLICATION AREAS

Where Can These Algorithms Be Used?

Routing

It solves a Traveling Salesman Problem–style task: find the shortest possible route that visits all selected cities or locations exactly once and returns to the starting point.

Scheduling

Arrange tasks or jobs in an efficient order based on processing time and priority. The result is displayed as an optimized schedule and Gantt chart.

Timetabling

Assign classes, teachers, and time slots while minimizing conflicts. The system generates an optimized timetable in a clear grid format.

Feature Selection

Select the most relevant features from a dataset to reduce complexity and improve model performance. The result shows selected features, relevance, and optimization fitness.

Routing Optimization - Find efficient routes using AI-inspired optimization algorithms.

Routing Constraints

• The route must start from the selected starting city/location.
• Every city/location must be visited exactly once.
• A city/location cannot be visited again before the route is completed.
• The route must return to the starting city/location.
• The route must form one complete connected tour.
• The algorithm should minimize the total travel distance.

SCHEDULING OPTIMIZATION

Scheduling Constraints

• Each task must be scheduled exactly once.
• Only one task can be processed at a time (single-machine scheduling).
• A task cannot start before the previous task is completed.
• Processing time for every task must be considered.
• Higher-priority tasks should be scheduled earlier where possible.
• The algorithm should minimize total completion time and scheduling delay.
