The AI-Inspired Routing Optimizer is a web-based application that implements and compares five AI-inspired optimization algorithms to solve routing problems.
The application finds optimized routes between multiple locations and compares the performance of different algorithms based on total distance and execution time.
It uses a Flask backend and an interactive web interface to display the generated routes and optimization results.

The project implements the following five optimization algorithms:
- **Genetic Algorithm (GA)**– Uses selection, crossover, and mutation to find an optimized route.
- **Simulated Annealing (SA)** – Improves routes by exploring different solutions and gradually reducing the probability of accepting worse solutions.
- **Ant Colony Optimization (ACO)** – Uses artificial ants and pheromone trails to find efficient routes.
- **Particle Swarm Optimization (PSO)** – Uses a population of particles that move towards better solutions.
- **Artificial Bee Colony (ABC)** – Simulates the foraging behaviour of honey bees to search for optimized routes.

Steps:
- Clone the repository
- install dependencies = pip install flask
- run the applications = python app.py

Working:
- Select the number of locations.
- Choose the optimization algorithm.
- Configure the algorithm parameters.
- Run the optimization process.
- View the generated route.
- Analyze the total distance and execution time.
- Compare the performance of different algorithms.
